# Unified Operational Roles & Dynamic Data Flow Plan

To address your request, we are implementing a robust and elegant role-based system (`Operator` vs `Director`) that establishes a seamless flow of data across both the Web command center and the Mobile native app.

## User Review Required

> [!IMPORTANT]
> **Role-Based Workflow Design**:
> - **Operator Role**: Can ingest logistics sources, analyze signals, and request action plans. However, they CANNOT execute actions directly. They must submit the plan for approval.
> - **Director Role**: Can view all telemetry, run analyses, approve/execute pending workflows directly (both on Web and Mobile), and bypass constraints.
> - **Synchronized Approvals**: We are introducing a shared `activeTrace` and `pendingApprovals` structure stored in `backend/data/mock_db.json` so that any plan generated by an Operator on Web can be immediately reviewed, approved, and executed in real-time by a Director on Mobile (and vice-versa).
